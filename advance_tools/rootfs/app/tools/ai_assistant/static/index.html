📨 Telegram bot

Create one with @BotFather. ⚠ Use a different bot than Notify Hub — Telegram allows only one listener per token.
Message the bot once — it replies with your chat ID. Only listed chats can give commands.

What can I say?

  • “Turn off all the lights.”
  • “Set the bedroom lamp to 50% and make it red.”
  • “Is the front door locked?” — “Lock it.”
  • “Set the living room to 21 degrees.”
  • “Open the garage” (asks for confirmation / PIN if protected).
  • “Which windows are open?” / “What's the temperature outside?”

The assistant answers in the language you use — Persian works.

Voice

Push-to-talk: hold the 🎤 button (or press it once to start and again to stop on devices without long-press), speak, release.

Wake word: tick the checkbox and leave the tab open — say “Hey <name>”, wait for the chime, then speak your command. Uses the browser's speech recognition; Chrome works best. The mic stays local — audio is not sent to this add-on.

Spoken replies use the browser's own voice; toggle 🔊 off to keep it silent.

Telegram

Create a bot with @BotFather, paste the token in Settings, send the bot any message, then add the chat ID it shows you to the allow-list. Text and voice notes both work — voice notes need an OpenAI API key for transcription (the chat brain can still be Claude or a local model).

Safety

Domains listed as protected (locks, alarm, covers by default) follow the safety rule: run freely, ask for confirmation, require the PIN, or be blocked. Confirmations appear as a button in this chat and as inline buttons in Telegram. Everything the assistant does goes through your Home Assistant user permissions — it can never do more than the add-on itself can.
